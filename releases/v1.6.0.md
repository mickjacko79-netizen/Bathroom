Draws a full A3 set from a room and its fixtures: floor plan, plan with wall units
and mirrors, four wall elevations, a freestanding vanity elevation, schedules and a
summary — exported as a 10-page PDF.

## Which file do I want

| | |
|---|---|
| **Bathroom-1.6.0-setup.exe** | Installs it, with a Start menu entry and a desktop shortcut. Per-user, so it needs no administrator. |
| **Bathroom-1.6.0-portable.exe** | Runs as it is, from anywhere — a USB stick, a network share. Nothing is installed. |

Windows x64. Neither is code-signed by a certificate Windows recognises, so
SmartScreen will show "Windows protected your PC" the first time — **More info →
Run anyway**.

Installing over any earlier version keeps your jobs. Nothing about how a job is
stored has changed since 1.0.0.

## What's new since 1.5.0

**Ask Claude can see the Draw tab.** Until now it could read and change the
drawing but stopped at the site measure — which is where a job usually starts, so
the two things you most wanted help with on a new job were the two it could not
reach.

It can now read the plan you have traced: how many walls, whether a scale has been
set, whether they close into a room, what doors and windows are on them, and the
wall lengths in millimetres — which is the number you are holding a tape measure
against. And it can bring that plan into the drawing, the same as the **Bring in
from Draw** button.

The useful part is what it says when a measure will not come in. There are only
really two reasons — no scale set, or corners that do not quite meet — and both
take about ten seconds to fix once you know which one it is. So rather than
failing, it names the one that is in the way.

Ask it *"what have I traced?"* or *"bring that in"*.

> **Bringing a plan in replaces the room and its walls**, so anything already
> placed on a wall may be affected. It is still a single undo step — `Ctrl+Z`
> takes the whole thing back — but on a job you have already fitted out, it is
> worth asking what is there first.

## What this needs, and what it costs

**Claude Code, installed once**: `npm install -g @anthropic-ai/claude-code`. The
panel says so if it is missing, and signing in happens in the panel — no terminal.

**Your existing Claude subscription.** The app runs Claude Code, which signs in as
you. There is no API key to obtain, paste, or store, and nothing is billed
separately from what you already pay for.

## Worth knowing before you install

The app opens a **listening port on this machine** while it runs — that is how
Claude reaches the drawing. Loopback only, so nothing off this machine can see it;
a cross-site `Origin` is refused, so a web page cannot drive it through your
browser; and the address carries a token kept in the app's own data folder.

What that does **not** stop is anything already running as you on this machine,
which can read that token file. If you would rather it were closed, **Claude →
Stop bridge**.

What Claude is allowed to touch is deliberately narrow — the drawing tools and
nothing else. No shell, no file edits, no other MCP server from your global
config, and a working directory of its own under the app's data folder.

Dictation runs on this machine. Nothing is recorded, nothing is written to disk,
and no audio leaves the computer.

## What's in it

- **Fixtures** — real Caroma products where the published geometry checked out
  against their stated sizes, and parametric symbols where it did not.
- **Showers** — screens and hinged doors either hand, tiled blade walls, rainheads
  on a wall arm or off the ceiling, handheld rails, twin outlets, niches, and falls
  from all four corners to the waste.
- **Tiling** — a datum with a gauge choice on the walls (full tile at the bottom,
  at the top, or split) and on the floor (full tile at either wall, or split).
- **Vanities** — per-cabinet kick height, or wall-hung with no kick; mirrors from
  10 mm deep and up to 2200 wide, set flush into the wall if you want; shaving
  cabinets with a mirror front and a recess.
- **Everything on a wall drags** into place by its grab handle, in plan or in
  elevation, to a set-out of its own. Moving one fixture moves that one and
  nothing else; anything it clears in height it simply passes.
- **Ask Claude** — read the job and change it by asking, including the traced
  plan in the Draw tab. Type it, or speak it.
- **SiteMeasure** for building the floor plan from measurements taken on site.
