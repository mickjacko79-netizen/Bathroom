Draws a full A3 set from a room and its fixtures: floor plan, plan with wall units
and mirrors, four wall elevations, a freestanding vanity elevation, schedules and a
summary — exported as a 10-page PDF.

## Which file do I want

| | |
|---|---|
| **Bathroom-1.5.0-setup.exe** | Installs it, with a Start menu entry and a desktop shortcut. Per-user, so it needs no administrator. |
| **Bathroom-1.5.0-portable.exe** | Runs as it is, from anywhere — a USB stick, a network share. Nothing is installed. |

Windows x64. Neither is code-signed by a certificate Windows recognises, so
SmartScreen will show "Windows protected your PC" the first time — **More info →
Run anyway**.

Installing over any earlier version keeps your jobs. Nothing about how a job is
stored has changed since 1.0.0.

## What's new since 1.2.0

One thing, arrived at in four steps: **you can talk to Claude about the drawing,
inside the app, and have it do the work.**

Click **Ask Claude** in the header. Ask what is on a wall and it tells you. Ask
for a roll holder beside the toilet and one appears while you watch. Everything
it does is a single undo step, so `Ctrl+Z` takes back whatever it did, exactly as
if you had done it by hand.

It reads and changes the drawing through eight tools — what is on this wall, what
can be drawn, add, move, change, remove, room size, show me a sheet. They speak
the app's own language: fittings by id, set-outs in millimetres from the start of
a wall, the band of height a fitting occupies. Where you ask for something and it
lands somewhere else, because another fitting was already standing there, it says
so rather than quietly obliging.

**Signing in happens in the panel.** It opens your browser, you sign in there, and
you paste back the one-time code the browser shows you. No terminal.

**There is a microphone beside Send.** What it hears goes into the box rather than
straight to Claude, so a sentence that came out wrong can be corrected before it
is sent. This is the dictation engine already in Windows — it needs no account and
no internet, and it gets most of a sentence right rather than all of it. If the
accuracy irritates you, Windows' own voice typing (`Win`+`H`) works in that box
too and is better.

## What this needs, and what it costs

**Claude Code, installed once**: `npm install -g @anthropic-ai/claude-code`. The
panel says so if it is missing.

**Your existing Claude subscription.** The app runs Claude Code, which signs in as
you. There is no API key to obtain, paste, or store, and nothing is billed
separately from what you already pay for.

## Worth knowing before you install

The app opens a **listening port on this machine** while it runs — that is how
Claude reaches the drawing. It is deliberately fenced: the loopback interface
only, so nothing off this machine can see it; a cross-site `Origin` is refused, so
a web page cannot drive it through your browser; and the address carries a token
kept in the app's own data folder.

What that does **not** stop is anything already running as you on this machine,
which can read that token file. If you would rather it were closed, **Claude →
Stop bridge**. It also takes a port at launch: if another copy of Bathroom already
has it, the bridge simply does not start and the Claude menu says so.

What Claude is allowed to touch is deliberately narrow — the drawing tools and
nothing else. No shell, no file edits, no other MCP server from your global
config, and a working directory of its own under the app's data folder. A question
about a towel rail cannot become an edit somewhere in your code.

Dictation runs on this machine. Nothing is recorded, nothing is written to disk,
and no audio leaves the computer.

## What's in it

- **Fixtures** — real Caroma products where the published geometry checked out
  against their stated sizes, and parametric symbols where it did not.
- **Showers** — screens and hinged doors either hand, tiled blade walls, rainheads
  on a wall arm or off the ceiling, handheld rails, twin outlets, niches, and falls
  from all four corners to the waste.
- **Tiling** — a datum with a gauge choice on the walls (full tile at the bottom,
  at the top, or split) and on the floor (full tile at either wall, or split).
- **Vanities** — per-cabinet kick height, or wall-hung with no kick; mirrors from
  10 mm deep and up to 2200 wide, set flush into the wall if you want; shaving
  cabinets with a mirror front and a recess.
- **Everything on a wall drags** into place by its grab handle, in plan or in
  elevation, to a set-out of its own. Moving one fixture moves that one and
  nothing else; anything it clears in height it simply passes.
- **Ask Claude** — read the job and change it by asking, in the app.
- **SiteMeasure** for building the floor plan from measurements taken on site.
