# Release notes

One file per released version, newest last. Each says what changed, what it needs,
and carries the SHA-256 of the two exes that were built from that commit — so a
copy of `Bathroom-1.6.0-portable.exe` found on a USB stick can be checked against
the file here rather than taken on trust.

    v1.0.0.md    the first packaged build
    v1.1.0.md    every fixture gets a place of its own
    v1.2.0.md    height counts — fittings that clear each other share the wall
    v1.5.0.md    Ask Claude: the panel, the sign-in, the microphone
    v1.6.0.md    Ask Claude can see the Draw tab

**1.3.0 and 1.4.0 have no notes, deliberately.** They were steps on the way to
1.5.0 and never left this machine, so there is nobody holding one to write for.
The v1.5.0 notes cover everything from 1.2.0 onwards.

These used to live in `desktop/dist/`, which is regenerated by every build and is
not in git — so the notes for a version disappeared the moment the next one was
built. They are here instead, which is why the older four have moved.

When handing someone an exe, take the matching file from here with it. The build
does not copy them into `dist/` — the exes and the notes are made at different
times by different things, and a copy that goes stale is worse than a file you
fetch when you need it.
